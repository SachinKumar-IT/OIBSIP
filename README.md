#  Data Science Mini Projects

This repository contains three Data Science and Machine Learning projects.

The projects demonstrate practical applications of Python, data analysis, data visualization, machine learning algorithms, and model evaluation.

## Projects Completed

### 1. Iris Flower Classification
**Task 1**

- Built a machine learning model to classify Iris flowers into three species: Setosa, Versicolor, and Virginica.
- Used the built-in Iris dataset from Scikit-learn.
- Performed Exploratory Data Analysis (EDA), data preprocessing, and model training.
- Implemented Logistic Regression and K-Nearest Neighbors (KNN).
- Evaluated model performance using accuracy, confusion matrix, and classification report.

**Folder:** `DataScience-Task1-IrisFlowerClassification`

### 2. Car Price Prediction
**Task 3**

- Developed a machine learning model to predict the selling price of used cars.
- Used the CarDekho vehicle dataset.
- Performed data cleaning, feature engineering, and exploratory data analysis.
- Implemented Linear Regression and Random Forest Regression.
- Evaluated models using MAE, RMSE, and R² score.

**Folder:** `DataScience-Task3-CarPricePrediction`

### 3. Sales Prediction
**Task 5**

- Developed a machine learning model to predict product sales based on advertising expenditure.
- Used TV, Radio, and Newspaper advertising data.
- Performed data visualization, correlation analysis, and data preprocessing.
- Implemented Linear Regression and Random Forest Regression.
- Evaluated model performance using MAE, RMSE, and R² score.

**Folder:** `DataScience-Task5-SalesPrediction`

## Installation and Setup

1. Clone this repository:

```bash
git clone https://github.com/SachinKumar-IT/OIBSIP.git
```

2. Navigate to the project directory:

```bash
cd OIBSIP
```

3. Install the required libraries:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn
```

4. Open the required project folder and launch its Jupyter Notebook.

5. Run the notebook cells sequentially to view the analysis, model training, evaluation, and predictions.

## Dataset Information

- **Iris Flower Classification:** Built-in Iris dataset provided by Scikit-learn.
- **Car Price Prediction:** CarDekho used-car dataset.
- **Sales Prediction:** Advertising dataset containing TV, Radio, Newspaper, and Sales features.

For the Car Price Prediction and Sales Prediction projects, ensure the required CSV datasets are placed in their respective project folders before running the notebooks.
